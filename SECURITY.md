# Security

If you believe you have found a security or privacy issue in this repository, please report it privately.

## Contact

- email: devs@put.io

Use private email for vulnerabilities or sensitive reports.

## Scope

Useful reports usually include issues involving:

- leakage or unsafe handling of app-specific passwords
- insecure storage or logging of sensitive account data
- unexpected exposure of private file or transfer metadata in Raycast
- unsafe publish or distribution behavior for the extension

## Disclosure

Please allow a reasonable amount of time to investigate and fix the issue before sharing details publicly.
